# Aprendizado em Docker & Apache Spark

Bem-vindo ao meu repositório de estudos! Este espaço foi criado para registrar os principais marcos do meu aprendizado em **Docker** e **Apache Spark**. 

A minha meta aqui não é apenas guardar código, mas sim documentar o processo de forma prática e didática. Para cada conceito ou ferramenta implementada, você encontrará:

* **Explicação Teórica:** Um breve resumo do que foi feito e o conceito por trás.
* **Código/Comandos:** Os scripts, Dockerfiles, comandos executados ou códigos em PySpark/Scala.
* **Finalidade e Contexto:** O motivo pelo qual executei aquilo no meu cenário de estudos.
* **Exemplos Práticos:** Casos de uso reais onde essa solução se aplica no dia a dia do mercado.

---

## 🚀 Tecnologias Foco

* **Docker:** Criação de containers, isolamento de ambientes para engenharia de dados, Docker Compose (para subir clusters Spark locais) e gerenciamento de volumes/redes.
* **Apache Spark:** Processamento de dados distribuído em larga escala, Spark SQL, Dataframes (PySpark), otimização de queries e manipulação de Big Data.
